# Unmapped Spotify Listens

A simple tool for finding Spotify listens in ListenBrainz that are not yet mapped to MusicBrainz.

## Live Tool

https://unmapped-spotify-listens.pages.dev/

## Features

- Fetch up to 1000 recent ListenBrainz listens.
- Show unmapped Spotify listens.
- Open the Spotify album or artist.
- Submit an album to Harmony.
- Search for the recording on MusicBrainz.
- Manually map a listen to a MusicBrainz recording.
- Filter results by artist.
- Saves your ListenBrainz username and API token locally in your browser.

## Usage

1. Enter your ListenBrainz username.
2. Enter your ListenBrainz API token.
3. Choose how many recent listens to fetch.
4. Click **Fetch Listens**.
